# buzzer-active
A demonstration of powering an active buzzer with an Arduino UNO board. Watch the demonstration below on YouTube. 

**Do not forget to turn your audio up.**

[![Watch on YouTube](https://i.postimg.cc/mkw8125W/active-buzzer.jpg)](https://youtu.be/l5wQF2TQJSk)

Electronic buzzers are DC-powered and equipped with an IC. The buzzer in this video
is an active buzzer, meaning it has a built-in oscillating source and will generate a sound
when electrified.

This is very simple connection--two F-M DuPont wires attach the buzzer to the GND and 12 pin on 
the Arduino. The code generates a few different sound patterns from the buzzer.
